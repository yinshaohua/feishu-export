# Milestone v0.1: M001 飞书多维表格导出

**Status:** SHIPPED 2026-05-15
**Phases:** 1-3
**Total Plans:** 7

## Overview

用户能够把飞书多维表格的视图导出为 Markdown 表格和 Excel 文件，复用现有浏览器登录态，无需额外 API token。

## Success Criteria

- [x] 多维表格 URL 在 `output/` 下生成同名 `.md` 和 `.xlsx`。
- [x] Excel 可正常打开，列头、数据和链接完整。
- [x] Markdown 包含正确字段名和记录数据。
- [x] 现有文档导出回归测试不受影响。
- [x] `npm run build` 无类型错误。

## Phases

### Phase 1: Bitable 数据提取核心

**Goal**: 拦截 `/clientvars` API，解压表格数据并生成 `BitableTable`。
**Plans**: 3 plans

### Phase 3: CLI 集成和端到端验证

**Goal**: 在现有 CLI 中接入多维表格导出并完成回归。
**Plans**: 2 plans

- [x] 03-02: 更新 README 并运行全量测试

## Key Decisions

- 使用 `/clientvars` API 响应而非 canvas DOM 作为数据源。
- 以 `viewMap` 列顺序作为导出字段顺序。
- 使用 `exceljs` 生成 Excel 工作簿。
- 输出命名沿用 `sanitizeFileName(baseToken)` 加日期后缀。

## Deferred

- 超过 200 条记录的分页导出。
- 从 SSR 响应获取真实表格标题。
- 多视图分别输出 Excel sheet。
- 需要真实登录态的浏览器端到端测试。
